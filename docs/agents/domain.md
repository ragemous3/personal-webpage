# Domain documentation

This is a single-context repository. Read [GLOSSARY.md](../../GLOSSARY.md) for domain vocabulary and relevant records in [docs/adr](../adr) before drafting tickets. Use the glossary's terms and identify any conflict with an accepted ADR.
