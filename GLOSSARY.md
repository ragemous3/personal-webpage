# Offline résumé assistant

The assistant answers questions about Rasmus using information from his résumé and site content.

## Language

**Offline assistant**:
The assistant that answers using a locally run language model and the available résumé content.
_Avoid_: Online assistant

**Retrieved context**:
The résumé or site passages selected as evidence for answering a visitor's question.
_Avoid_: Model knowledge

**Mode**:
Where the assistant answers: Local uses a model on the visitor's device; Online uses a remote provider.

**Selected settings**:
The visitor's latest valid configuration choices, including changes waiting for a response to finish.

**Active settings**:
The configuration currently used by the assistant. An ongoing response keeps its starting configuration.
